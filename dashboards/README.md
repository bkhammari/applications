# Dashboards

Interactive HTML views. GitHub shows only the source of an `.html` file, not the
rendered page, so use one of the ways below to actually open them.

## Open the rendered pages

These links render the live pages. They are private to Baha's claude.ai account,
so they open only when signed in as the owner.

- **Deadline board** (`deadlines.html`): https://claude.ai/code/artifact/c85e04ff-92e1-4828-b633-5506b5c4170a
- **Application command center** (`status.html`): https://claude.ai/code/artifact/71fc7204-917c-44b2-bde2-f31ffa94b6ec
- **AD5 abstract-reasoning trainer** (in `../eu/ad5-prep/abstract-trainer.html`): https://claude.ai/code/artifact/581ba38e-c35c-448c-9a30-4712fa38b2f8

## Other ways to open

- Download the `.html` file from GitHub (the raw view) and open it in any browser. Each file is self-contained, so it works offline apart from the Google Font, which falls back cleanly.
- If you enable GitHub Pages on this repository, the files are served at a `github.io` URL and open directly.

## Files

- `deadlines.html`, every application deadline, requirement, and fit, sorted by urgency.
- `status.html`, one status view across PhD, EU, bridge internships, industry, and scholarships.

Both are static snapshots. Update them from the folder trackers as things move.
