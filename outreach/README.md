# PhD & Research Outreach Tracker

Central hub for all PhD, doctoral-programme, and interim-position outreach.
Each target has a ready-to-send email draft in the linked folder. Formal
LaTeX cover letters and the research proposal live under
[`../cover-letters/academic/`](../cover-letters/academic/) and
[`../research/proposal/`](../research/proposal/).

_Last updated: August 2026._

**Deadlines at a glance:** see `deadlines-dashboard.html` (visual board of every
program's deadline, requirements, and fit).

## Standard attachments

Unless noted otherwise, each first contact carries:

- **CV** — `../cv/academic/academic_cv.tex`
- **Research proposal** — `../research/proposal/research-proposal.tex`
  (general) or the Bonn-tailored version under `../cover-letters/academic/bonn/`
- **Thesis abstract** — `../research/abstracts/masters-thesis-abstract.tex`
  (offer it; attach on request to keep the first email light)

Keep first emails to CV + proposal. Some servers reject mail with multiple
PDF attachments (this happened with RWI — status 550 5.7.1), so if a message
bounces, resend with **no attachments** and offer to send them on request, or
use a contact form.
